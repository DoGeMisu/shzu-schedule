# 石大课表 (SHZU Schedule)

> **非官方声明**：本项目**非石河子大学官方软件**，由在校学生利用**课余时间**出于学习目的独立开发维护，与学校官方及教务部门无任何关联。

石河子大学课表安卓应用：自动登录学校统一身份认证（CAS），抓取教务系统整学期课表，本地离线渲染，支持深浅主题、自定义背景、自定义加课与桌面小组件。

## 功能特性

### 课表

- **自动登录**：学号密码一次保存，CAS 统一认证自动续期，Cookie 持久化免频繁登录
- **MFA 兼容**：CAS 触发短信二次验证时自动停留验证页，手动验证后流程无缝继续
- **整学期课表**：一次抓取全学期数据本地保存，按周快速过滤渲染
- **周次自动识别**：从教务教学周历接口获取第 1 周周一日期与学期总周数，拒绝硬编码
- **节次时间动态提取**：作息时间表（如 1-2 节 10:00-11:40）从教务页面实时提取
- **课程详情**：点击卡片放大展开，重叠课程（同一格多门课）逐门完整展示
- **拖动调位置**：长按 700ms（含震动反馈）进入拖动模式，松手后可撤销/应用，随时一键重置布局
- **交互体验**：滑动切周、同课同色、今日高亮、空课周提示、开屏动画（可在设置中一键开关）
- **分周加载**：启动只渲染本周并立即显示，其余周次在页面出图后后台预生成，切周直接复用缓存
- **自动检查更新**：启动后后台静默比对一次教务课表，有差异才弹窗询问，不打扰正常使用
- **自定义加课**：点「＋ 加课」再点格子，即可添加自己的课程（自习、社团、旁听等），**已有课的格子也能叠着加**；可选「仅本周一次」只在这一周显示一张卡片；与教务课表分两套通道存储，刷新教务数据不会覆盖
- **重叠提示**：自己主动叠加的格子用琥珀色描边；教务同步后新撞上的用红色描边 + 感叹号，并可在设置里选择重叠时优先显示哪一门

### 外观

- 深色 / 浅色主题切换，全局 0.35s 过渡
- 自定义图片背景（相册选取），课程卡片、星期栏、按钮自动半透明，网格无白底
- 自适应图标：前景位图 + 同色系渐变背景，适配圆形 / 方形 / 水滴等系统遮罩

### 桌面小组件（v1.1.2 新增）

- **接下来的课程**：主屏直接显示按时间先后排序的后续课程，一门一行
- **课程配色**：每行课程名使用与课表一致的课程颜色，左侧有同色标记条
- **地点与时间**：课程名下方标注「地点 · 时间段」，今天 / 明天用相对日期
- **玻璃拟态**：半透明磨砂背景 + 细描边，圆角 22dp，不遮挡壁纸
- **深浅自适应**：浅色 / 深色两套配色，按小组件尺寸自动选择，也可点顶部 ◐ 按钮手动切换
- **多尺寸**：支持 1×2 / 1×3 / 2×2 等网格，高度越大显示行数越多（最多 4 行）

> ⚠️ **注意**：部分国产 ROM（如 ColorOS / 澎湃 OS）会屏蔽第三方应用的小组件，
> 小组件中心可能不显示「石大课表」。这是系统限制，非应用问题。

│ NextCourseWidgetProvider  桌面小组件 RemoteViews 渲染    │

                         │ addJavascriptInterface ↔ evaluateJavascript

- 语言：Java（零 Kotlin）
- 界面：WebView + HTML/CSS/JS（课表、弹窗、动画全部为网页实现）
- 兼容：Android 7.0+（minSdk 24），适配 Android 12+ 系统 SplashScreen

## 工作原理

1. **登录链路**：访问教务系统 → 无会话则 302 到 CAS → 注入 JS 自动填表登录 →（如触发短信验证则等待用户手动完成）→ 凭据在到达教务系统后才落盘
2. **课表入口探测**：教务首页扫描链接（href 特征 xskb/kbcx → 文字特征“课表”）→ 空结果复扫 → 超时转入预设 URL 猜测，多层兜底
3. **DOM 解析**：金智教务课表表格按 `th`（节次+时间）/`td`（7 列课程）结构提取，`font[title]` 属性区分教师/教室/周次/班级/备注等字段，支持同格多课程拆分
4. **周次推导**：教学周历接口获取第 1 周周一日期与学期覆盖范围 → 推算总周数 → `weekMatches()` 解析“3-16(周)”“单双周”等表达式

## 构建

环境要求：JDK 21、Android SDK（compileSdk 34，需含 `platforms/android-34` 与 `build-tools/34.0.0`）、Gradle 8.4 + AGP 8.3.2

```bash
# 国内推荐（Gitee，直连）
git clone https://gitee.com/m1sucode/shzu-schedule.git
# 或 GitHub
git clone https://github.com/DoGeMisu/shzu-schedule.git

cd shzu-schedule
gradle assembleDebug
# 产物路径：app/build/outputs/apk/debug/（具体文件名见下方命名规则）
```

产物按版本号自动命名（由 `applicationVariants.all` 完成，无需手动改名）：

| 构建类型 | 文件名 |
|---|---|
| release | `shzu-schedule-v<versionName>.apk` |
| debug | `shzu-schedule-v<versionName>-debug.apk` |

> **更新服务 Key 是可选项**：`BuildConfig.UPDATE_API_KEY` 取本地 `keystore.properties` 的
> `updateApiKey`（不入库），也可以在 `gradle.properties` 里用 `shzuUpdateApiKey` 覆盖。
> 未配置时构建仍可成功，但会退化为匿名受限下载通道（每 IP 每天 5 次），不影响其它功能。

> **首次构建必须自行配置 SDK 路径**：在项目根目录新建 `local.properties`，写入本机 Android SDK 的绝对路径（该文件**不入库**，每个人的路径都不同）：
>
> ```properties
> sdk.dir=C\:\\Android\\Sdk
> ```
>
> 注意 Windows 路径需按 Java Properties 规则转义（`\` 写成 `\\`，冒号写成 `\:`）。
> 也可以用环境变量 `ANDROID_HOME` 代替，或在 Android Studio 中打开项目，IDE 会自动生成该文件。
>
> 若报 `Failed to apply plugin 'com.android.internal.application'`，通常是 SDK 路径不对或缺少 `platforms/android-34`、`build-tools/34.0.0`，用 SDK Manager 补齐即可。

## 隐私与安全

- **密码加密存储**：学号密码使用 Android Keystore（AES-256-GCM）加密后落盘，密钥不出安全硬件；旧版明文凭据打开应用时自动迁移
- **网络白名单**：仅允许访问 `*.shzu.edu.cn`，其余跳转一律拦截
- **证书校验**：SSL 错误只对校内域名放行，其余直接拒绝（防中间人）
- **禁明文流量**：默认策略禁止 HTTP 明文，仅校内域名放宽
- **不参与备份**：`allowBackup=false`，应用数据无法被备份导出
- **无第三方服务器**：课表与凭据不经过任何第三方，本项目不含任何硬编码凭据
